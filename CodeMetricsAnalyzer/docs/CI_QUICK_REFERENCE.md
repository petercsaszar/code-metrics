## ?? New Jobs Added

### `build_analyzer`
- **Stage**: build
- **Purpose**: Compiles the analyzer tool
- **Output**: `./analyzer-tool/`
- **Duration**: ~30 seconds

### `code_metrics`
- **Stage**: analyze (NEW)
- **Purpose**: Analyzes code quality
- **Input**: TicTacToeGame.sln
- **Output**: HTML + XML reports
- **Duration**: ~1-2 minutes

## ?? Usage Examples

### View Latest Report
```bash
# Via GitLab Pages (after deployment)
https://yourname.gitlab.io/tictactoegame/metrics/

# Via Artifacts (immediately after job)
CI/CD ? Pipelines ? Latest ? code_metrics ? Browse
```

### Check Issue Count
```bash
# Look for in job logs
TOTAL_CODE_METRICS_ISSUES=42
```

### Download XML Report
```bash
# From artifacts
curl -o metrics.xml \
  "https://gitlab.com/api/v4/projects/PROJECT_ID/jobs/JOB_ID/artifacts/code-metrics-report/metrics.xml"
```

### Fail Pipeline on Threshold
```yaml
# Add to code_metrics job script
- |
  ISSUE_COUNT=$(jq '.Metrics[-1].TotalIssues' ${ANALYZER_OUTPUT}/history.json)
  if [ "$ISSUE_COUNT" -gt 50 ]; then
    echo "? Too many issues: $ISSUE_COUNT (threshold: 50)"
    exit 1
  fi
```

## ?? Customization Options

### Analyze Specific Project
```yaml
- dotnet analyzer-tool/CodeMetricsAnalyzer.dll \
    analyze TicTacToeGame.Model.Basic/TicTacToeGame.Model.Basic.csproj \
    --report-output ${ANALYZER_OUTPUT}
```

### Run Only on Master
```yaml
code_metrics:
  only:
    - master
```

### Change Report Location
```yaml
variables:
  ANALYZER_OUTPUT: "custom-metrics-folder"
```

### Adjust History Retention
```csharp
// In HtmlReportGenerator.cs
.Take(100)  // Change to 50, 200, etc.
```

## ?? Common Issues

| Issue | Solution |
|-------|----------|
| Tool not found | Check `build_analyzer` job succeeded |
| No history | Verify caching is enabled |
| Pages not updating | Ensure running on `master` branch |
| XML report missing | Comment out `junit` report (optional) |
